Specifications – HandmadeMarket 
1. Project Objective
 E-commerce platform where users can both sell and buy handmade products and materials used to create them, using a single dual-role account.

2. Target Users
Artisans selling handmade products
Sellers of materials and supplies
Buyers seeking unique handmade items or materials
3. Core Functionalities
A. Buyer Features
Product browsing by category: Handmade / Materials
Advanced search with filters: category, price, etc.

B. Seller Features
Product listing: Handmade items or Materials
Seller dashboard with stats and notifications

C. Admin Features
User and seller account management
Product/review moderation
Analytics and commission management

Frontend: React.js
Backend: Node.js + Express
